## 2. 方法總覽

```
BERT embedding ─→ ① 商品語意分群（UMAP+HDBSCAN）
                      ├─ 精準層：細群 ~110（追單一商品單價）
                      └─ 故事層：合併成超類型 K=25（講「多花在哪大類」）
                  ─→ ② 重複購買群篩選 + 每月加權單價時序
                  ─→ ③ 個人增量分析：這個月 vs 平常月均，拆成「變貴 / 買更多」
```

## 3. 商品語意分群

### 3.1 主方法與結果
以 BERT embedding 經 **UMAP(5D, cosine) + HDBSCAN** 分群：

| 指標 | 結果 |
|---|---|
| 群數 | ~110（自動決定，不需預設 K） |
| noise 比例 | 6.9% |
| purity / homogeneity（對 6 類） | 0.99 / 0.95 |
| silhouette | 0.88 |

分群品質佳，例：美式咖啡群（中/大/特大冰美式）、牛肉麵店餐點群（清燉/紅燒/三寶）、手搖飲群（四季春/奶茶/紅茶）。

### 3.2 方法對照實驗（為什麼選 UMAP+HDBSCAN）
非監督任務以 6 類標籤為外部基準（圖：`outputs/exp_clustering.png`）：

| 組合 | noise | silhouette | 說明 |
|---|---:|---:|---|
| raw768 + HDBSCAN | 32% | 0.70 | 高維密度估計失準，noise 高 |
| PCA30 + HDBSCAN | 34% | 0.69 | 同上 |
| **UMAP5 + HDBSCAN（採用）** | **7%** | **0.88** | UMAP 把 noise 砍 ~5 倍、品質最高 |

> 另：未降維直接 KMeans(K=6) 可還原 6 類消費（**ARI 0.97、NMI 0.92**）→ 證明 BERT embedding 品質高。

### 3.3 與 baseline 比較（驗證方法價值）
（圖：`outputs/exp_slide_baselines.png`）

| 方法 | 覆蓋率 | noise | silhouette |
|---|---:|---:|---:|
| Regex 關鍵字（規則下限） | 0.44 | 56% | 0.26 |
| TF-IDF + HDBSCAN（傳統 ML） | 0.64 | 36% | 0.71 |
| BERT + K-Means（消融） | 1.00 | 0% | 0.83 |
| **BERTopic（Ours）** | **0.93** | **7%** | **0.88** |

→ Ours 同時解決「**語意辨識不清**」（覆蓋率 44%→93%，能合併「大/中/特大冰美式」變體）
與「**雜訊干擾**」（noise 36%→7%）。BERT+KMeans 的 0% noise 是假象——強迫每點進群、無離群機制。

## 4. 分群設計：為什麼三人一起分群（pooled）

- **分群＝建一本公共「商品字典」**（商品身份與「誰買」無關），故三人 pooled；
  **診斷＝讀各自帳本**（增量分析帶 user_id 分人計算）。
- 實測「三人分開分群」（`per_user_pipeline/`）：**小資料量者崩潰**——user 2 可分析類型
  砍半（8→4）、粒度崩塌（59→8 群）、失去跨人可比（共享商品 pooled 100% → per-user 0%）。
  （圖：`per_user_pipeline/outputs/exp_per_user_clustering.png`）→ 確認採 **pooled**。

---

## 5. 顆粒度：兩層式商品分類

細群（~110）對「增量分析」太細，故再把細群中心向量合併成超類型。比較 K=15/25/35：

| K | 講故事評估 |
|---|---|
| 15 | 太粗，最大群含 134 款（漢堡+雞肉+正餐揉一團）無法命名 |
| **25** | **採用**：飲料/咖啡/正餐/拉麵分開，bar 數適中 |
| 35 | 類別更純但略瑣碎 |

→ **最終兩層**：精準層（細群，追單一商品）＋ 故事層（超類型 K=25，講「多花在哪大類」）。

## 6. 主結果：個人增量分析（Layer 3 核心）

**定義**：每人「這個月」= 最新月；「平常」= 之前所有月的月均。對每個類型：
```
變貴 price_effect = (P1−P0)·Q1      買更多 qty_effect = (Q1−Q0)·P0
ΔS = 變貴 + 買更多 = 這個月 − 平常月均（在此類型上的花費差）
```
資料清理：剔除佔位品名（代收/塑膠袋/餐飲費）、類型單價一致性過濾、每類型≥10 筆。
（圖：`outputs/step3c_user{0,1,2}.png`、超類型版 `outputs/step3d_K25_user{u}.png`）

### 兩個核心發現

**① 個人通膨是「品項分化」的，不是齊漲。**
user 1 主要類型單價變化：清燉牛肉 **+11%**、清爽沙拉飯 **+9%**，但原味波士頓 **−6%**、紅茶持平。

**② 多花的錢常來自「買更多」而非「變貴」。**
例：user 1 本月在「清燉牛肉類」多花 **1003 元 = 買更多 860 + 變貴 143**
（平常每月 2.25 份 → 本月 6 份；單價 229→253）。

## 7. 限制

- **資料偏食**：飲食佔 ~82%，增量結論主要適用高頻飲食類。
- **發票覆蓋率**：現金/訂閱/轉帳無發票，分析範圍限「可由電子發票觀察的消費」。
- **低頻品項**：出現 <10 次者無法納入商品群（良性邊界，通膨本就需重複購買）。
- **超類型命名**：目前用前 3 名品項自動標籤，未來可用 LLM 命名成「手搖飲類」等乾淨大類名。
- **使用者異質**：user 2 筆數少（428），個別結論信賴度較低。

---

## 8. 結論

1. 以 BERT embedding + UMAP + HDBSCAN 建立**高品質商品語意分群**（noise 7%、purity 0.99），
   並有完整方法對照與 baseline 驗證其必要性。
2. 設計**兩層商品分類體系**（細群追價 + 超類型講故事），並以實驗否決「分開分群」。
3. 完成**個人消費增量分析**，能拆解「這個月多花的錢」為**變貴 vs 買更多**，
   揭示個人通膨的品項分化特性。
