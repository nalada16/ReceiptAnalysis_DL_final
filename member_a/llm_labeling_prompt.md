# Task 1：LLM 預標注 Prompt

> 成員 A 半自動標注流程中，對模糊樣本送 LLM 批次預標注所使用的 prompt。
> LLM 輸出 `label`、`confidence`、`reason` 三欄，經人工審核後移除輔助欄位，只保留最終標籤。
> 為控成本，先對「品名 + 店家」組合去重，相同組合只標一次，再回填原始資料。

---

你是一個電子發票消費分類助手。我會提供一份 CSV 資料。

請根據：

- 品名（item_clean）
- 店家名稱（store_clean）
- 金額區間

幫每筆資料新增三個欄位：

- label, confidence, reason

---

## 分類類別（只能選一個）

1. 飲食
2. 交通
3. 購物
4. 3C 電子
5. 娛樂
6. 醫療健康
7. 教育
8. 其他

---

## 分類原則

### 1. 優先依據「實際消費用途」

請判斷消費本質，而不是只看店家類型。例如：

- 超商買咖啡 → 飲食
- 超商買耳機 → 3C 電子
- 百貨買衣服 → 購物
- 書店買參考書 → 教育

### 2. 店家名稱是重要上下文

很多發票品名語意不足，例如：商品、餐飲、套餐、食品、飲品。此時請結合店家名稱推論。例如：

- 「商品 + 康是美」可能偏醫療健康
- 「商品 + 全聯」可能偏購物
- 「套餐 + 麥當勞」偏飲食
- 「服務費 + 停車場」偏交通

### 3. 金額只能作為輔助資訊

金額區間可協助判斷，但不能作為唯一依據。例如：

- 高金額可能是 3C 或醫療
- 小額飲料通常偏飲食

但不能只因金額高就直接分類為 3C。

## 類別定義與範例

### 飲食
包含：餐廳、飲料店、早餐店、食品、咖啡、外送餐點、超商食品
範例：珍珠奶茶、雞腿便當、拿鐵咖啡、Foodpanda、麥當勞套餐

### 交通
包含：大眾運輸、計程車、停車費、加油、ETC、租車、高鐵、台鐵、悠遊卡加值
範例：Uber、停車費、高鐵車票、中油加油、台灣大車隊

### 購物
包含：日用品、衣物、百貨、家居用品、一般生活消費
範例：衣服、洗衣精、寢具、寶雅生活用品、全聯商品

### 3C 電子
包含：電子產品、手機配件、電腦設備、遊戲硬體、電子周邊
範例：滑鼠、鍵盤、USB-C 線、SSD、AirPods、iPhone 配件

### 娛樂
包含：電影、遊戲、KTV、串流平台、展覽、娛樂活動
範例：Netflix、Steam、威秀影城、KTV、遊戲點數

### 醫療健康
包含：藥品、保健食品、診所、醫院、醫療器材、健康相關用品
範例：維他命、感冒藥、掛號費、血壓計、隱形眼鏡藥水

### 教育
包含：書籍、線上課程、補習、學費、文具（教育用途明顯時）、考試報名
範例：Udemy、TOEIC 報名、參考書、補習班學費

### 其他
無法明確判定時使用。例如：品名與店家資訊不足、不屬於前述類別、難以推論用途。

---

## 特殊判斷規則

**規則 1：3C 優先於購物**
若商品明顯為電子設備或配件（滑鼠、鍵盤、耳機、充電器），請優先分類為「3C 電子」，不要分類為購物。

**規則 2：食品優先歸類飲食**
即使店家是便利商店、百貨公司、超市，若購買的是食品、飲料、餐點，仍分類為「飲食」。

**規則 3：保健與藥品優先歸類醫療健康**
即使是在屈臣氏、康是美、寶雅，購買維他命、藥品、醫療用品時，請分類為「醫療健康」。

---

## confidence 定義

- 0.9 ~ 1.0：非常明確
- 0.7 ~ 0.9：大致明確
- 0.4 ~ 0.7：有模糊性
- 0.0 ~ 0.4：資訊不足

---

## 輸出格式（非常重要）

請直接輸出完整 CSV，保留原本所有欄位。並在最後新增：

- label
- confidence
- reason

不要省略任何列。不要使用 markdown code block。不要解釋。只輸出 CSV。
